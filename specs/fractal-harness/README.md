# Фрактальный харнес — пакет реализации

Статус: спецификация первой реализации. Код продукта ещё не написан. Пакет предназначен для исполнителя, которому нужны заранее принятые архитектурные решения, небольшие задачи и проверяемые результаты.

Цель: самостоятельная среда, где типы данных, операции, запросы, вызовы, память, цикл, инструменты, интерфейс и организация работы определяются плагинами через общую метамодель. Каждый плагин может объявить слоты для других плагинов. Составное поддерево заменяет компонент при сохранении его контракта.

## Как пользоваться

Исполнять один атом из PLAN.md за раз. Контракты и ожидаемые результаты тестов не подгонять под реализацию. При расхождении сначала локализовать ошибку; архитектурное изменение требует отдельной записи решения и обновления связанных тестов.

Файлы contracts.ts и tests являются входом для реализации, а не заявлением, что харнес уже работает. Исполняемые тесты требуют адаптер будущего продукта; без него они намеренно завершаются ошибкой, а не пропускаются.

Проверить сам пакет: npm ci, затем npm run check из этой папки. Проверяются TypeScript-контракты, Gherkin, локальные ссылки, полнота тестовых ID и отсутствие циклов зависимостей. Это не запускает будущий продукт.

Фактический результат проверки: [VERIFICATION.md](VERIFICATION.md).

Приоритет источников внутри пакета: CONTRACTS.md и contracts.ts → RUNTIME.md и UI-AND-DATA.md → тестовые оракулы → PLAN.md → REVIEW.md. Противоречие нормативных контрактов считается дефектом спецификации; его нельзя молча разрешать по порядку документов.

## Завершение первой версии

Один и тот же продукт запускается как одиночный вопрос–ответ и как среда с агентским циклом, памятью, проверками, сессиями, вкладками, историей, ветками и проектами. Удаление этих предметных плагинов оставляет работоспособный технический host. Сторонний плагин добавляет новый тип, операции, хранение, UI и новый слот; другой плагин расширяет этот слот без изменений host.

Все проверки имеют конкретные свидетельства: команды, коды выхода, протоколы тестов и локальный пользовательский сценарий. Наличие файлов реализации само по себе не закрывает атом.
